# grok-bots

Public [Grok Bot](https://x.ai) share links (`https://x.ai/bot/<id>`). Official Grok Bot has no template store, so people share bots through those URLs. This repo only lists bots we opened ourselves and confirmed the share page loads and shows Add to Grok Bot.

## Disclaimer

This list is unofficial and is not affiliated with xAI. The bots here are third-party. Adding a bot is not an endorsement, and “verified” only means the share page loaded and showed Add to Grok Bot when we opened it. Share links can change or stop working.

## How to contribute

Add one object to the matching use-case file under [`data/`](data/). Do not add rows to this homepage. See [CONTRIBUTING.md](CONTRIBUTING.md).
