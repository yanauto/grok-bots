# grok-bots

A small curated list of public [Grok Bot](https://x.ai) share links (`https://x.ai/bot/<id>`). Official Grok Bot has no template store, so people share bots through those URLs. This repo only lists bots we have opened ourselves and confirmed the share page loads and shows Add to Grok Bot.

## Disclaimer

This list is unofficial and is not affiliated with xAI. The bots here are third-party. Adding a bot is not an endorsement, and “verified” only means the share page loaded and showed Add to Grok Bot when we opened it. Share links can change or stop working.

## How to add a bot

1. Open the `https://x.ai/bot/<id>` page and confirm it loads and shows Add to Grok Bot.
2. Add one row: name, a one-line role, the share URL, and the date you checked it.
3. Open a pull request.

See [CONTRIBUTING.md](CONTRIBUTING.md) for the checklist.
